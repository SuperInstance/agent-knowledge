# MUSIC → COGNITION — The Complete Pattern Map

## Hook

> Music theory spent 500 years developing formal tools for multi-agent creative coordination. We just never called it that.

## Reveal

Every concept in music theory has a direct mapping to agent cognition and collaboration:

| Music | Cognition | Crate |

| Voice | Collaborator | agent-jam |

The key insight: **the ternary algebra {-1, 0, +1} is the protocol between every layer.** Dissonance/rest/consonance in music = conflict/neutral/agreement in cognition = reject/abstain/approve in agents. Same algebra, different domains.

## Connect

This pattern map explains WHY the music crates exist alongside the agent crates. They're not separate domains — they're the SAME domain viewed from different angles:

- `flux-algebra` defines the mathematical space → `agent-voice-leading` navigates it
- `ternary-jam` implements the jam session → `agent-jam` generalizes it
- `agent-rhythm` detects patterns → `agent-groove` optimizes timing
- `counterpoint-engine-rs` enforces rules → `agent-voice-leading` applies them to transitions

The pollination: music theory → cognitive architecture → agent collaboration → productive output.
